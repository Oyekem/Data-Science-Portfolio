##  1.  [Crypto Data Pipeline & Real-Time Analytics System](https://github.com/Oyekem/data_pipeline)
An end-to-end data engineering and analytics project that collects live cryptocurrency market data from the CoinGecko API, processes and stores it in a cloud-hosted PostgreSQL database, engineers technical indicators for analysis, and delivers real-time insights through an interactive Streamlit dashboard. The project demonstrates modern data engineering practices, including ETL automation, cloud deployment, containerization, CI/CD, and dashboard development.

**Tools**: Python • PostgreSQL • Neon • CoinGecko API • Pandas • SQLAlchemy • Streamlit • Plotly • Docker • GitHub Actions • Render

**Key Highlights**
 - Designed and implemented a production-oriented ETL pipeline to extract live cryptocurrency market data from the CoinGecko API and load it into a cloud-hosted Neon PostgreSQL database.
 - Automated scheduled data ingestion using GitHub Actions, enabling continuous data collection without manual intervention.
 - Built modular pipeline components for data extraction, transformation, validation, logging, configuration management, and database loading.
 - Engineered advanced technical indicators including RSI, MACD, EMA, Bollinger Bands, momentum, lag variables, and volatility metrics for market analysis and forecasting.
 - Developed an interactive Streamlit dashboard featuring real-time market monitoring, historical trend analysis, multi-asset comparison, technical indicator visualization, and predictive analytics.
 - Containerized the application using Docker to ensure consistent deployment across development and production environments.
 - Deployed the solution on Render using environment-based configuration and a cloud-hosted PostgreSQL database.
 - Improved pipeline reliability through centralized logging, retry mechanisms, configuration management, and automated CI workflows.
