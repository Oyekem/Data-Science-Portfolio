  - Automated scheduled data ingestion using GitHub Actions, enabling continuous data collection without manual intervention.
  - Built modular pipeline components for API extraction, data transformation, validation, logging, and database loading following production-oriented software engineering practices.
  - Engineered technical indicators including RSI, MACD, EMA, Bollinger Bands, momentum, lag variables, and volatility metrics for predictive analytics.
  - Developed an interactive Streamlit dashboard featuring real-time market monitoring, historical analysis, multi-coin comparison, technical indicator visualization, and forecasting.
  - Containerized the application using Docker to ensure consistent deployment across environments.
  - Deployed the application on Render using environment-based configuration and cloud-hosted infrastructure.
  - Implemented centralized logging, retry logic, configuration management, and CI automation to improve pipeline reliability and maintainability.
